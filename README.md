# DesignVolt

Десктопный векторный редактор уровня Figma на чистом Rust: GPU-рендер, свой UI-слой и много плавных анимаций.
Цель — функциональный аналог Figma (без Community) и при этом быстрее и легче CPU-рендерных клонов.

*A desktop Figma-like vector design tool written in pure Rust: GPU rendering on [Vello](https://github.com/linebender/vello), a hand-written UI layer and smooth animations.*

> **Статус: ранняя стадия.** Есть оболочка приложения, дизайн-система, экран проектов и первый рабочий холст: можно рисовать фрейм, прямоугольник и эллипс, выделять, переносить, менять размер, дублировать, удалять и отменять. Документ автоматически сохраняется на диск; нет вращения, групп, векторов и текста (см. [roadmap](docs/roadmap.md)).

## Что уже есть

- Окно без системной рамки со своим верхним баром (домик, текущее место, свернуть / развернуть / закрыть).
- Светлая (синий акцент) и тёмная темы, русский и английский интерфейс, переключение в настройках без перезапуска.
- Приветственный экран, экран проектов и экран настроек.
- Проекты: вложенные папки, перенос перетаскиванием, переименование, корзина с восстановлением, избранное, дублирование, мультивыбор (Ctrl / Shift / кружки на карточках), контекстное меню, поиск, сортировка (сохраняется).
- Свои виджеты и анимации: кнопки, поля ввода с шорткатами как в браузере (выделение, буфер обмена, undo/redo), меню, модальное окно, переключатель.
- Редактор: бесконечный холст с точечной сеткой (зум колесом с Ctrl, панорамирование колесом, пробелом или средней кнопкой), инструменты V / F / R / O / H, рисование фрейма, прямоугольника и эллипса, выделение (клик, Shift, рамка, слои), перенос с привязкой к соседним объектам и красными направляющими, изменение размера за 8 маркеров, поворот за углом (Shift — 15°), стрелки, Ctrl+D, Delete, Ctrl+Z / Ctrl+Y; в правой панели X, Y, W, H, угол и радиус вводятся числами.
- Производительность проверена бенчмарком: 10 000 фигур рисуются за 3,9 мс на кадр целиком, 100 000 — за 42 мс (RTX 5070).

## Стек

Rust 2024, [Vello](https://github.com/linebender/vello) на wgpu для рендера, winit для окна, skrifa для текста и шрифтов, kurbo для геометрии, arboard для буфера обмена. Свой слой интерфейса, свой движок анимаций, без egui / iced / webview. Шрифт — Golos Text, иконки — Phosphor (оба с открытой лицензией, файлы лицензий лежат рядом). Подробности и причины выбора: [docs/stack.md](docs/stack.md), [docs/decisions.md](docs/decisions.md).

## Запуск

Нужны свежий стабильный Rust (edition 2024) и видеокарта с поддержкой DirectX 12 или Vulkan. Проект разрабатывается и проверяется на Windows 11; Linux и macOS пока не проверялись.

```sh
cargo run -p designvolt                  # запуск приложения
cargo test --workspace                   # тесты всех крейтов
cargo fmt --check && cargo clippy --workspace --all-targets -- -D warnings
cargo dev                                # пересборка и перезапуск при сохранении (нужен cargo-watch)
cargo run --release -p dv-render --example bench -- 10000   # замер холста на N фигурах (без окна)
```

В редакторе **Ctrl+Shift+B** создаёт страницу из 10 000 фигур для проверки производительности; внизу холста показываются масштаб, число объектов и время построения сцены.

Данные пользователя (профиль, настройки, проекты, папки) лежат в `%APPDATA%\DesignVolt` (`~/.config/designvolt` на Linux/macOS) в простых текстовых файлах. Чтобы увидеть приветственный экран снова, удалите эту папку. Содержимое проектов сохраняется само (через секунду после правки, при выходе из редактора и при закрытии) в `documents/<id>.dvd` рядом с остальными данными.

## Структура

```
crates/
├── dv-core/      документ (фрейм, прямоугольник, эллипс), обратимые команды, undo/redo; без UI и графики
├── dv-geom/      матрицы, границы, точное попадание, R-tree для отсечения и выбора
├── dv-render/    зум и панорамирование, отсечение, сцена Vello; пример bench
└── dv-ui/        кит интерфейса: рисование, текст (Golos Text), иконки, токены тем, анимации, виджеты
apps/desktop/     приложение `designvolt`: окно, верхний бар, экраны (приветствие, проекты, настройки),
                  библиотека проектов и хранилище, редактор (холст, панели, инструменты), i18n RU/EN
docs/             стек, архитектура, дизайн-система, структура, ADR, журнал, роадмап
assets/           шрифт и иконки
```

Границы крейтов и правила зависимостей: [docs/architecture.md](docs/architecture.md).

## Дорожная карта

Коротко (полностью — в [docs/roadmap.md](docs/roadmap.md)):

1. **M0** Проверка стека: холст, зум и панорамирование, замер на 10 000 фигур. *(готово, стек подтверждён)*
2. **M1** Ядро документа и холст: модель, команды, undo/redo, выбор, перенос и размер готовы; цвет, группы и порядок слоёв впереди; сохранение, поворот, привязки и ввод свойств готовы. *(в работе)*
3. **M2** Дизайн-система UI. *(в основном готова)*
4. **M3–M5** Векторы, стили, эффекты, текст, фреймы, Auto Layout.
5. **M6–M9** Файлы и экспорт, компоненты и переменные, прототипирование, Dev Mode.
6. **M10+** Совместная работа, плагины, ветки, поиск и доступность, администрирование.
