# Решения (ADR)

Формат: `ID — дата — решение`. Почему. Последствия. Менять только новой записью.

## D-001 — 2026-10-19 — Язык и стек рендера
Чистый Rust (edition 2024). Холст — **Vello** на **wgpu**; UI — **Masonry/Xilem** со своей дизайн-системой и анимациями. Не egui/iced/slint/dioxus/tauri.
Почему: GPU-рендер векторов на compute-шейдерах быстрее CPU-рендера (tiny-skia, как в FigCraft); один рендер на холст и панели, нет склейки окон. Цена: молодые библиотеки и собственные виджеты. План Б для UI — Freya или Iced.
Последствия: версии закрепляем и сверяем на docs.rs; детали — `docs/stack.md`.

## D-002 — 2026-10-19 — Архитектура: движок отдельно от UI
Workspace `dv-core ← dv-geom ← dv-render ← dv-ui ← apps/desktop`. Все изменения документа — команды (undo/redo). Идея взята у FigCraft и WordVolt. Подробно: `docs/architecture.md`.

## D-003 — 2026-10-19 — Правила работы ИИ перенесены из WordVolt
Режим экономии токенов (без скриншотов и живых прогонов, список «Проверьте сами»), ведение `plan.md`/`decisions.md`/`log.md`, лимиты файлов (≤300 строк), git-воркфлоу, токены темы. Отличия: стек Vello/Masonry вместо GPUI; зависимости только из стека; `unsafe` запрещён; код и комментарии по-английски, чат по-русски.

## D-004 — 2026-10-19 — Визуальный язык
Тёмная тема по умолчанию; акцент индиго → фиолетовый (`#6366F1` → `#A855F7`); раскладка как в Figma (слои/страницы слева, свойства справа, плавающий тулбар снизу); мягкий скруглённый стиль + glass только для плавающих слоёв; шрифт Inter (OFL). Почему: тёмный фон не искажает цвета контента, раскладка привычна пользователям Figma, glass дорог для рендера, поэтому ограничен плавающими элементами. Риск: в Vello нет backdrop blur — сначала имитация (прозрачность + тень + блик), настоящий blur отдельным проходом wgpu. Подробно: `docs/design-system.md`.

## D-005 — 2026-10-19 — Иконки: Phosphor (SVG, MIT)
Решение пользователя. Файлы SVG кладём в `assets/icons/phosphor/` (regular/bold/fill), подключаем только нужные. Новый крейт не нужен: path-данные парсятся `kurbo::BezPath::from_svg` и рисуются Vello как обычные фигуры (цвет из токенов, анимируемый). Лицензия MIT — файл LICENSE рядом с иконками.

## D-006 — 2026-10-19 — Glass: настоящий backdrop blur
Решение пользователя: делаем реальное размытие фона, а не имитацию. Реализация: холст и панели рендерятся в текстуру; для glass-слоёв отдельный проход wgpu (двухпроходный gaussian/kawase blur по нужной области) и композиция поверх с полупрозрачной заливкой и бликом. Vello этого не умеет, поэтому свой pipeline на `wgpu` (в стеке). Пока блюр не готов, glass-слои рисуются как прозрачная заливка + тень + блик (временная имитация, единый API `glass_panel`, чтобы замена не трогала виджеты). Риски: производительность на слабых GPU (блюр только под видимыми glass-слоями, пониженное разрешение), порядок композиции. Задача вынесена в plan.md.

## D-007 — 2026-10-19 — Светлая тема позже
Сначала только тёмная. Светлая тема добавляется после M2 заменой набора токенов (`theme/colors.rs`), поэтому в виджетах нет захардкоженных цветов.

## D-008 — 2026-10-19 — Экраны и локальное хранение профиля/проектов
Приложение управляет экранами через трейт `Screen` (`src/input.rs`): Welcome (ввод имени, до 20 символов, любые печатные символы, считаем символы, не байты) → Projects (поиск, сортировка Name/Last modified/Created с направлением, создание, сетка карточек) → Editor (макет). Профиль и список проектов хранятся в `%APPDATA%\DesignVolt` (`profile.txt`, `projects.txt`) простым текстовым форматом с экранированием: `serde` не входит в стек. Запись атомарная (temp + rename). Папки, вставка из буфера обмена и выделение мышью в поле ввода пока не сделаны.

## D-009 — 2026-10-19 — Кастомный верхний бар и окно без системной рамки
Окно создаётся с `decorations(false)`; бар (`src/titlebar.rs`, 40 px) рисуется Vello поверх всех экранов: слева домик (на экран проектов) и «чип» текущего места (All projects / имя проекта), по центру логотип и название, справа свернуть / развернуть / закрыть (закрыть краснеет). Перетаскивание — `drag_window`, двойной клик по пустому месту разворачивает, изменение размера — `drag_resize_window` по невидимой рамке 6 px (`src/chrome.rs`). Экраны получают область под баром (`App::sync_viewport`), мышь сдвигается на высоту бара. На Welcome домика и чипа нет. Ограничение: у окна без рамки Windows не рисует системную тень и скругление.

## D-010 — 2026-10-19 — Светлая тема с синим акцентом по умолчанию, переключатель тем
Палитры `LIGHT` и `DARK` (`src/theme/colors.rs`), активная выбирается в рантайме; виджеты вызывают токены-функции (`bg_panel()`, `accent()`…), сырых hex нет. По умолчанию светлая: фон `#F3F6FC`, панели белые, акцент синий `#2563EB → #4F8CFF`; тёмная (индиго → фиолетовый) сохранена. Границы и разделители рисуются базовым цветом `overlay()` (белый на тёмной, тёмно-синий на светлой), тени масштабируются `shadow_k`. Переключатель — кнопка солнце/луна в верхнем баре; выбор пока не сохраняется между запусками. Тест на контраст WCAG AA для текста в обеих темах. Уточняет D-004 и D-007.

## D-011 — 2026-10-19 — Буфер обмена: крейт arboard
Для Ctrl+C/X/V в полях ввода добавлен `arboard` (без default-features, только текст), обёртка `src/clipboard.rs`; ошибки буфера игнорируются. Решение принято по требованию пользователя «все шорткаты как в браузерном инпуте»; крейт вне исходного стека (`docs/stack.md`). Редактирование вынесено в чистую модель `widgets/text_edit.rs` (выделение, слова, undo/redo с объединением набора, тесты), виджет `text_input.rs` отвечает за мышь, буфер и отрисовку.

## D-012 — 2026-10-19 — Локализация RU/EN и экран настроек
Строки интерфейса живут в `src/i18n.rs`: enum `Msg` + `tr(Msg)`, активный язык — thread-local (как палитра), поэтому смена языка действует мгновенно, без перезапуска. Язык по умолчанию — русский. Динамические строки (`projects_count` с русскими склонениями, `ago`, `edited`) — функции там же. Хардкод строк в виджетах запрещён. Названия проектов — пользовательские данные и не переводятся; новые создаются как «Без названия N» / «Untitled N» на текущем языке. Настройки (тема, язык) сохраняются в `%APPDATA%\DesignVolt\settings.txt` (`theme=light|dark`, `lang=ru|en`), по умолчанию — светлая, русский. Экран настроек — отдельная страница (`screens/settings.rs`), не модалка: профиль (смена имени, ≤20 символов), тема, язык; открывается шестерёнкой в верхнем баре или кликом по профилю в боковой панели, Esc — назад. Кнопка переключения темы из бара убрана (D-010 уточнён).
