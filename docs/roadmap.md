# Roadmap DesignVolt — полный клон Figma (без Community)

Цель: функциональный паритет с Figma Design + собственные улучшения в скорости. Исключено: Figma Community (маркетплейс файлов, плагинов, виджетов, шаблонов). Порядок вех идёт от рискованного к безопасному и от фундамента к надстройкам: без движка и дизайн-системы остальное не построить. Текущая веха и задачи — в `plan.md`.

Статус: `[ ]` не начато, `[~]` в работе, `[x]` готово (+ дата).

## Часть A. Figma Design

- [ ] Трансформации: move, resize (с shift/alt), rotate, flip, nudge стрелками
- [ ] Группы, фреймы, порядок слоёв (z-order), lock, hide
- [ ] Привязки (snap), умные направляющие, измерения расстояний (alt)
- [ ] Линейки, направляющие, сетки (pixel grid, layout grid)
- [ ] Viewport: зум к выделению / ко всему, миникарта-навигация, hand tool
- [ ] Буфер обмена внутри приложения (copy, paste, paste in place, duplicate)
- [ ] Scale tool (K): пропорциональное масштабирование с эффектами и обводками
- [ ] Multi-edit: правка свойств у нескольких слоёв сразу, смешанные значения («Mixed»)
- [ ] Smart selection: выравнивание и распределение, равные отступы между слоями

- [ ] Align / distribute / tidy up, Arrange (bring to front / send to back)

### M2. Дизайн-система UI

### M3. Векторное редактирование и стили
- [ ] Pen tool, Безье, редактирование узлов и ручек, pencil

- [ ] Булевы операции: union, subtract, intersect, exclude
- [ ] Заливки: solid, linear / radial / angular / diamond gradient, image fill, несколько заливок на слой
- [ ] Обводки: inside / center / outside, dash, caps, joins, variable width, arrowheads
- [ ] Эффекты: drop shadow, inner shadow, layer blur, background blur

- [ ] Эффекты текста: градиентная и image-заливка текста, обводка и тени у текста, glow, 3D/extrude, warp (arc, wave, flag, bulge), текст по пути/кривой, outline-текст, per-character стили

- [ ] Цветовое пространство (sRGB, Display P3), пипетка, цветовой пикер

- [ ] Симуляция дальтонизма (protanopia, deuteranopia, tritanopia, achromatopsia)

### M4. Текст

## Часть B. Остальные продукты Figma (после полного Design)

- **FigJam-аналог (whiteboard):** стикеры, коннекторы, фигуры, таймер, голосование, шаблоны, виджеты
- **Slides-аналог:** презентации на том же движке, режим показа, заметки докладчика
- **Sites/Buzz-аналоги:** публикация сайтов из дизайна, массовое производство баннеров по шаблону — только если останется ресурс
- **Motion-аналог (анимация):** таймлайн, ключевые кадры, пользовательские стили анимации, анимация текста по символам/словам/строкам, аудио на таймлайне, экспорт MP4/WebM/Lottie/dotLottie
- **Make-аналог (код из дизайна и промптов):** code layers, прототипы на коде из фреймов, импорт из GitHub/npm, бэкенд-заготовки — зависит от M12 и выбора AI-провайдера
- **Specs-аналог:** общее место для описания намерений, визуальных исследований и технических деталей рядом с дизайном
- **Weave-аналог:** новый продукт Figma, назначение уточнить по документации перед планированием
- **AI-агент и MCP:** агент в файле (поиск, вставка нод в промпты, свои skills), правила библиотек в markdown, MCP-сервер для внешних инструментов (база в M11)
- **Education и командные курсы:** материалы и проекты — низкий приоритет

## Порядок и зависимости
M0 → M1 → M2 → (M3 ‖ M4) → M5 → M6 → M6b → M7 → M8 → M9 → M10 → M11 → M11b → M12 → M13 → M14 → M15.
Веха M14 (поиск) частично нужна раньше: базовый поиск слоёв идёт вместе с панелью слоёв в M2.
Критичные зависимости: M5 (Auto Layout) нужен перед M7 (компоненты) и M8 (прототипы); M10 (коллаборация) требует стабильной модели документа из M1–M7, поэтому модель сразу проектируется под CRDT (иммутабельные id, операции вместо снимков).
